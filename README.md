# LinkVault

Локальное хранилище ссылок с тёмным интерфейсом.

## Запуск
Откройте `index.html` в браузере. Для публикации загрузите всю папку проекта в Netlify (Deploy manually) либо подключите Git-репозиторий.

## Возможности
- Добавление, редактирование и удаление ссылок
- Поиск, сортировка, категории и избранное
- Сетка и список
- Сохранение в LocalStorage
- Экспорт и импорт JSON

## Важно
Данные хранятся только в браузере и на устройстве, где вы добавляли ссылки. Публикация на Netlify не создаёт общую библиотеку и не синхронизирует данные между пользователями. Для общей библиотеки потребуется серверная база данных и авторизация.
