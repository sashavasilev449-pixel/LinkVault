# LinkVault

Личное хранилище ссылок с тёмным интерфейсом. Проект подготовлен для публикации через **GitHub Pages**.

## Публикация на GitHub Pages

1. Распакуйте архив.
2. Откройте свой репозиторий GitHub.
3. Нажмите **Add file → Upload files**.
4. Загрузите все файлы из архива в корень репозитория: `index.html`, `style.css`, `app.js`, `links.js`, `search.js`, `storage.js` и `README.md`.
5. Нажмите **Commit changes**.
6. Откройте **Settings → Pages**.
7. В разделе **Build and deployment** выберите **Deploy from a branch**.
8. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
9. Подождите завершения публикации и откройте адрес сайта из блока GitHub Pages.

## Возможности

- Добавление, редактирование и удаление ссылок
- Поиск и сортировка
- Категории и избранное
- Переключение сетки и списка
- Экспорт и импорт библиотеки в JSON
- Сохранение данных в LocalStorage браузера
- Адаптация под мобильные устройства

## Важно о хранении данных

Ссылки хранятся локально в браузере на конкретном устройстве. GitHub Pages публикует только сам сайт и не синхронизирует личные библиотеки между устройствами или пользователями. Для синхронизации понадобится отдельная база данных и сервер.

## Внешние ресурсы

Шрифт Inter и иконки Lucide загружаются с внешних CDN. Для их отображения при открытии сайта требуется подключение к интернету.
